📋 Informações Importantes

⚠️ OBS1: 📋 SEPARAÇÃO As ordens de serviços com itens faltantes ou separação parcial irão gerar uma nova requisição quando os itens faltantes constarem no recebimento. Ou seja, aguardamos a entrega do fornecedor para continuar a separação, ou entregamos o pedido do cliente com as quantidades de cada item separado fechando a ordem de serviço (não gera nova requisição para a quantidade de itens faltantes ou separados parcialmente).
⚠️ OBS2: 📋 SEPARAÇÃO Para gerar uma requisição conforme os itens vão dando entrada no recebimento, a ordem de serviço deve estar em aberto - isso irá acontecer de forma automática.
🔍 Sempre Verificar: ✅ CONFERÊNCIA Analisar a situação e erros de cada ordem de serviço, garantir que esteja 100% separada e conferida para finalização.
📋 RC com Múltiplos Itens: 🏪 ARMAZENAGEM RC com mais de um item deve ser armazenada item a item.
🏢 Filial - Tabela de Conversão: 📦 RECEBIMENTO No modelo filial, sempre analisar a tabela de conversão após inserir o XML.
🎯 Separação Discreta: 📋 SEPARAÇÃO Das 5 opções de separação disponíveis, sempre escolher a segunda opção: separação discreta.

Recebimento de Mercadorias

🏭 Modelo 1 - Matriz

Processo simplificado sem previsão de fornecedores, focado em recebimento imediato e integração rápida.

🏢 Modelo 2 - Filial

Processo com análise de XML e tabela de conversão, seguindo todos os passos de validação.

🏭 Recebimento Modelo 1 - Matriz

  1. Sem Previsão de Fornecedores
    Não temos previsão de fornecedores para este modelo.
  2. Início do Recebimento
    Para darmos entrada no WMS, iniciamos um recebimento imediato.
  3. Integração de Volumes
    Volumes são integrados em uma RC (etiquetas onde posso colocar mais de um item).
    Para paletes fechados: faço a impressão da quantidade de paletes como volumes
  4. Apontamento
    Para finalizar a RC fazemos um apontamento (confirmação de quantidades por itens e descrição de itens).
  5. Habilitação de Requisições
    Para finalizar a RC, habilitamos as requisições (definição de local de destino de cada segmento).
  6. Finalização
    Feito todo o processo, todas as RC's estão aptas a endereçamento.

🏢 Recebimento Modelo 2 - Filial

  1. Entrada de XML
    Informamos o XML na entrada da nota fiscal (sem pular passos).
    1.1 - Sempre analisar a tabela de conversão
  2. Início do Recebimento
    Para darmos entrada no WMS, iniciamos um recebimento imediato.
  3. Integração de Volumes
    Volumes são integrados em uma RC (etiquetas onde posso colocar mais de um item).
    Para paletes fechados: faço a impressão da quantidade de paletes como volumes
  4. Apontamento
    Para finalizar a RC fazemos um apontamento (confirmação de quantidades por itens e descrição de itens).
  5. Habilitação de Requisições
    Para finalizar a RC, habilitamos as requisições (definição de local de destino de cada segmento).
  6. Finalização
    Feito todo o processo, todas as RC's estão aptas a endereçamento.

Armazenagem

📋 Guia Tratar/Requisição

Nesta aba temos 3 opções principais de operação:

📦 Armazenagem

Armazenar a RC conferida no local apropriado do estoque.

↩️ Devolução Ordem

Acontece quando retornamos algum item dentro de uma ordem de serviço.

🔄 Retorno UA Agrupada

Acontece quando retornamos algum item dentro da RC.

🎯 Processo de Armazenagem

  1. Navegação
    Navegar na opção tratar → armazenar recebimento → localizar a RC.
  2. Opções de Armazenagem
    Vamos ter os seguintes campos:
    • Armazenar itens parcial: armazena uma quantidade do produto em um endereço e o restante em outro endereço
    • Armazenar item com saldo total: permanece todo o saldo do item no endereço de destino
    • Armazenar todos os itens: armazena todos os itens com o saldo total no endereço de origem (⚠️ atenção nessa opção)
  3. Preenchimento de Informações
    Ao escolher a opção de armazenagem, preencher:
    • Posição de origem: bipar o QR CODE da etiqueta
    • Código do item: se tiver mais de um item na RC, replicar para todos os itens
    • Posição de destino: endereço onde vamos alocar o produto
    • Quantidade: quantidade do item que vamos alocar (sugestão: armazenar todo o saldo do item em um endereço)

Separação

🎯 Processo de Separação Discreta

Em operação, clicar em separação. Temos 5 opções de separação - escolher a segunda opção: separação discreta.

  1. Configuração de Impressão
    Configurar a impressão para a impressora mais próxima (definir impressão por setor).
  2. Impressão do Movimentador
    Fazer a impressão do movimentador (etiqueta VL).
  3. Informar Movimentador
    Informar o movimentador no campo (VL) no campo movimentador.
  4. Bipar Posição
    Bipar a posição informada pelo coletor para a coleta do picking.
  5. Informar Código do Item
    Informar o código do item a ser separado.
  6. Informar Quantidade
    Informar a quantidade a ser separada.
  7. Tratamento de Falta de Estoque
    Se caso não tiver a quantidade pedida na separação:
    • Saltar o item e procurar a mesa de operação (separador)
    • Mesa de operação: listar a ordem de serviço, retornar
    • Procurar o produto e estornar
    • Fazer o ajuste da posição para o saldo correto
    • Esperar o sistema atualizar novamente
    • Separador sair e entrar na ordem - item volta com saldo corrigido
  8. Saída Manual (Sem Saldo Físico)
    Se não tiver saldo físico:
    • Ir em produtos, filtrar o código do produto
    • Adicionar uma saída manual
    • Escolher o tipo de saída (avaria ou padrão CD)
    • Informar a quantidade da saída
    • Clicar em adicionar
Importante: Replicar este processo para todos os itens da ordem de serviço.
✅

Checkout/Conferência

🔍 Processo de Conferência

Para a conferência, vamos analisar a quantidade de volumes que irá gerar (fazer impressão de etiquetas de volumes baseado na separação).

Se a conferência não tiver a necessidade de fazer impressão, conferir com a VL de origem.
  1. Bipar Movimentador
    Bipar o movimentador (VL) para iniciar o processo.
  2. Processo com Novos Volumes
    Se tiver a necessidade de mais volumes:
    • Bipar o volume de origem
    • Bipar o novo volume impresso
    • Bipar o item que vamos inserir no novo volume
    • Inserir a quantidade
    • Repetir se tiver a necessidade de mais volumes
  3. Processo sem Novos Volumes
    Se não tivermos a necessidade de um novo volume:
    • Bipar o movimentador (VL)
    • Bipar o volume de origem
    • Inserir ou bipar o código do produto
    • Inserir a quantidade
  4. Finalização
    Feito ambos os processos, clicar em finalizar.

Movimentações de Produtos por Endereços

🎯 Tipos de Movimentação

Ao acessar os favoritos, temos várias opções. A opção movimentar/endereçar é onde fazemos transferências de produtos de um endereço para outro.

Primeiro passo: Identificar qual tipo de movimentação vamos fazer:

📦 Saldo Parcial

Movimentar item com saldo parcial - conseguimos transferir a quantidade de um item parcialmente entre endereços.

📋 Saldo Total

Movimentar itens com saldo total - movimenta a quantidade total de cada item entre endereços.

🏪 Todos os Itens

Movimentar todos os itens - movimenta o saldo total de todos os itens que constam no endereço.

🔄 Procedimento Geral

Para todas as operações devemos seguir estes passos:

  1. Posição de Origem
    Indicar a posição de origem (onde o item está armazenado).
  2. Quantidades (se parcial)
    Informar as quantidades se a movimentação for parcial.
  3. Posição de Destino
    Informar a posição de destino (novo endereço do item).
⚙️

Ajustar Endereço (Batman)

🛠️ Processo de Ajuste de Endereço

  1. Bipar Endereço
    Bipar o endereço que será ajustado.
  2. Informar Item
    Bipar ou informar o código do item.
  3. Informar Quantidade
    Informar a quantidade a ser processada.
  4. Selecionar Operação
    Irão aparecer três operações disponíveis:

➕ Adicionar

Adiciona a quantidade informada ao estoque do endereço.

🔧 Ajustar Todo Item

Ajustar todo item com a quantidade lançada (substitui o valor atual pelo informado).

➖ Debitar

Opção para retirada de quantidades totais ou parciais de cada item por endereço (ajustes).
